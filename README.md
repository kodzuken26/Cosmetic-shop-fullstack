Сайт интернет-магазин по продаже корейской косметики "Seulmate"

Сайт написан на React+TypeScript+Django. Для формирования API используется DRF, а для получения данных с API на фронте используется Redux. 
Для того чтобы установить все зависимости для бэка нужна команда "pip install -r requirements.txt"

Для запуска нужно запустить frontend командой npm run dev, 
для бэка нужно перейти в backend/backCosmetic и выполнить команды "venv/scripts/activate" и "python manage.py runserver"

На сайте представлен каталог товаров с фильтрами и поиском, главная страница с слайдером, и регистрация пользователя
